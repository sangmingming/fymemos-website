# 云笺 Yunjian · 官方网站

本站是 [云笺（Yunjian）](https://github.com/sangmingming/FlyerNotes) 的官方网站，基于 [Astro](https://astro.build/) + [Tailwind CSS 4](https://tailwindcss.com/) 构建，并部署在 Vercel。

## 内容

- `/` 首页：Hero / 核心卖点 / 特性 / 截图 / 技术栈 / FAQ / 下载 CTA
- `/privacy` 隐私政策

## 开发

```sh
npm install
npm run dev          # 本地开发，http://localhost:4321
npm run build        # 生产构建
npm run preview      # 本地预览构建产物
```

## 部署

直接推送到 main 分支，Vercel 会自动构建并发布。

## 协议

网站代码本身以 MIT 协议开源；云笺 App 不开源，其代码仓库为 GitHub 私有仓库，未以任何开源协议发布。
